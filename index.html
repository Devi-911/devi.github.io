Agentic Gemini Civic Tech

Bangalore Smart Waste Management System

AI-enabled civic operations platform with GPS simulation, real-time route optimisation, and per-ward personalisation. Features an interactive map, proximity alerts within 500m, a driver console, and escalation workflows — demonstrating end-to-end AI system design at city scale.

GitHub Repo Live App ↗

Product Vision

Eliminate manual waste-collection dispatching in Bangalore's wards by replacing radio-based coordination with an AI-driven platform that routes drivers in real time, personalises collection schedules per ward density, and auto-escalates missed pickups — reducing citizen complaints and idle truck time.

User Personas

  • Driver — needs turn-by-turn optimised routes and real-time updates on priority stops.
  • Ward Admin — monitors coverage, reviews escalation logs, adjusts schedules.
  • Citizen — receives proximity alerts (<500m) and can report missed pickups.

AI Architecture

  • Prompt Engineering — structured prompts feed ward density + GPS data to Gemini to generate optimised daily routes and escalation summaries.
  • Function Calling — Gemini calls get_ward_load(), trigger_escalation(), and update_driver_route() to act on live data without human dispatch.

Metrics & Results

  • 🗺️ Route generation: <3s per ward using Gemini function calls
  • 📍 Proximity alert accuracy: 500m geofence with real-time GPS simulation
  • ⚡ Escalation auto-trigger: zero manual dispatch for missed stops
  • 👤 3 distinct personas served from a single AI model layer

LLM-Driven BPMN/DMN Automation Governance

BPMN/DMN AI Testing & Validation Platform

AI sandbox for business automation governance — upload, edit, validate, and simulate BPMN/DMN models with LLM-driven audits. Supports live XML editing, visual debugging, automated test generation, and standards-compliant export. Directly applicable to enterprise developer platform governance.

GitHub Repo Live App ↗

Product Vision

Make BPMN/DMN model quality a first-class, automated concern — so enterprise automation teams can detect compliance issues, logic errors, and test gaps before production deployment, without relying on specialist manual review. Governance as a guardrail, not a gate.

User Personas

  • Process Modeller — uploads BPMN/DMN files, iterates on live XML, and exports validated versions.
  • QA / Test Engineer — runs AI-generated test cases against decision tables and process flows.
  • Platform PM — reviews audit reports to track standards compliance across the team's automation portfolio.

AI Architecture

  • Prompt Engineering — role-framed system prompts instruct Gemini to act as a BPMN/DMN standards auditor, returning structured JSON with issue type, severity, and remediation suggestion.
  • Function Calling — model calls validate_xml(), generate_test_cases(), and export_compliant_model() to operationalise audit findings.

Metrics & Results

  • ✅ Audit turnaround: <5s per model vs hours of manual review
  • 🧪 Test case generation: auto-produces edge-case scenarios from DMN tables
  • 🔍 Visual debug feedback on live XML edits in real time
  • 📤 Standards-compliant export ready for production deployment
